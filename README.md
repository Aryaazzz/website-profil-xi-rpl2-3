    # Refleksi Individu 
    1. Apa perbedaan bekerja sendiri dengan bekerja menggunakan Git dan GitHub?
   -Bekerja Sendiri: Seperti menulis dokumen di Notepad tanpa tombol Undo setelah file ditutup—jika salah ketik atau file terhapus, data tidak bisa dikembalikan.
   -Git & GitHub: Seperti memiliki "mesin waktu" dan "papan pengumuman bersama". Anda bisa melihat riwayat revisi kapan saja dan bekerja bersama orang lain di satu proyek tanpa saling bertabrakan.

    2.Apa manfaat branch? 
      -Eksperimen Aman: Anda bebas mencoba fitur baru di kertas buram. Kalau gagal atau error, tinggal buang (delete branch) tanpa merusak file asli.

     -Tidak Mengganggu Kode Utama: Kode utama yang sudah jadi dan lancar tidak akan terganggu sampai fitur baru selesai dan diuji.

     -Bisa Kerja Barengan: Teman Anda bisa mengerjakan bab 1 di cabang A, Anda mengerjakan bab 2 di cabang B, lalu digabung jika sudah selesai.
     
    3 .Mengapa Pull Request diperlukan?
         Manfaat utamanya:

          -Pemeriksaan Satpam (Cek Error): Mencegah kode yang rusak atau bug langsung masuk dan merusak aplikasi utama.

        -Minta Pendapat: Teman atau guru bisa melihat kode Anda, memberikan masukan, atau menyuruh merapikannya dulu.

         -zin Gabung: Menjadi tombol "konfirmasi" untuk menggabungkan hasil kerjaan dari cabang (branch) Anda ke proyek utama.

   4.Apa manfaat Code Review?
     Manfaat utamanya:

       -Mencari Error: Menemukan bug atau kesalahan ketik lebih cepat.

        -Kode Lebih Rapi: Memastikan kode mudah dibaca oleh siapapun.

        -Saling Belajar: Media berbagi trik dan cara koding yang lebih bagus antar-teman tim.

    5.Error apa yang paling sulit kalian selesaikan?
       Logic Error (Error Logika): Program berjalan lancar tanpa pesan error sama sekali, tetapi hasilnya salah. Mencari tahu di baris mana perhitungan atau jalurnya meleset sering kali membutuhkan proses debugging baris demi baris yang memakan waktu lama.

   6.Bagaimana kalian menemukan solusinya?
       cek Ulang Operator & Urutan: Periksa kembali simbol logika yang digunakan (misal: terbalik antara < dan >) serta urutan perkalian/pembagian yang mungkin lupa diberi tanda kurung ().

    7.Apa kontribusi terbesar kalian dalam kelompok? membuat fitur kontak yang isinya akan ada kontak dari masing-masing individu kita

    8.Jika menjadi programmer profesional, kebiasaan apa dari kegiatan ini yang akan kalian pertahankan?.
       Memanfaatkan Git & Branching Secara Disiplin: Mengisolasi setiap pembuatan fitur baru atau perbaikan di branch tersendiri serta melakukan commit secara berkala. Ini memastikan kode utama selalu stabil dan aman dari bahaya crash.
